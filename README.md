# Atividade Prática - Sistemas Operacionais

**Aluno:** Gustavo Romão


Automação com Threads: abertura do Bloco de Notas e escrita automática de texto.

Requisitos atendidos:
  - Parte 1: Thread 1 abre o Bloco de Notas do Windows.
  - Parte 2: Thread 2 escreve automaticamente um texto no Bloco de Notas.
  - Parte 3: mensagens de início/fim de cada thread são exibidas no terminal.

Para aumentar ou diminuir esse tempo, altere `TEMPO_ANTES_DE_ABRIR` em `threads.py`.

Antes de executar, instale as bibliotecas necessárias (uma única vez):
    pip install pyautogui pygetwindow

Este script foi feito para rodar no Windows.
